# การเงินและสุขภาพ — เว็บแอปส่วนตัวบน Google Sheet

เว็บสำหรับบันทึกและดูภาพรวมการเงินส่วนตัว + ผลตรวจสุขภาพรายปี ทำงานด้วย **Google Apps Script**
เก็บข้อมูลไว้ใน Google Sheet "งบประมาณประจำปี" เดิม (สร้างแท็บใหม่ชื่อขึ้นต้นด้วย `App_` แท็บเดิมไม่ถูกแก้ไข)
และ**เปิดได้เฉพาะบัญชี Google ของเจ้าของเท่านั้น**

## มีอะไรบ้าง

| หน้า | ทำอะไรได้ |
|---|---|
| 📊 ภาพรวม | รายรับ / รายจ่าย / เงินออม / คงเหลือของเดือน, อัตราการออมเทียบเป้า 20%, แถบงบประมาณรายหมวด, กราฟ 12 เดือน, ความคืบหน้าเป้าฉุกเฉิน-เกษียณ, เงินให้ยืมที่ค้าง, รายการประจำที่ยังไม่บันทึก |
| 🧾 รายรับ-รายจ่าย | บันทึก/แก้/ลบรายการ (แนบรูปใบเสร็จได้), กรองตามปี/เดือน/ประเภท/หมวด/บัญชี/คำค้น, สรุปรายปี (หมวด × เดือน), รายการประจำเดือนแบบกดบันทึกทีเดียว |
| 🗓️ แผน/คาดการณ์ | **แผนรายเดือน** (ตารางหมวด × เดือน แก้ได้ทุกช่องเหมือนในชีต, ค่าตั้งต้นจากงบ/รายการประจำ/เงินเดือน+โบนัส), เตือนเดือนที่เงินไม่พอ, **แผน vs จริง** (รายเดือน/ทั้งปี), **คาดการณ์ถึงเกษียณ** (เงินเดือนขึ้น, เงินเฟ้อ, ผลตอบแทน → ถึงเป้า 4.8 ล้านปีไหน), **แผนผ่อน** ของชิ้นใหญ่ (ขึ้นในแผนทุกเดือน + เตือนให้บันทึกงวด) |
| 📈 เงินออม/ลงทุน | ลงเงิน 1 ครั้งแบ่งเข้าหลายกอง (เช่น เงินสำรอง THB / เงินสำรอง USD / กองทุน), กอง USD กรอกเรทตอนซื้อและคิดมูลค่าด้วยเรทปัจจุบันอัตโนมัติ, บันทึกยอดสิ้นเดือน, กำไร/ขาดทุน, กราฟมูลค่า |
| 🤝 เงินให้ยืม | รายการให้ยืม (รหัส Dept-xxx), รับชำระเป็นงวด (ดอกเบี้ย + เงินต้น), คำนวณคงเหลือ/สถานะ/เกินกำหนดอัตโนมัติ — **นับเฉพาะดอกเบี้ยเป็นรายรับ** |
| 🏛️ ภาษี | ดึงรายได้ทั้งปีจากรายการรายรับ, กรอกค่าลดหย่อน, คำนวณภาษีขั้นบันได + ได้คืน/จ่ายเพิ่ม, แก้ตัวเลขเองได้ และลองเปลี่ยนตัวเลขเพื่อจำลองได้ทันที |
| 🩺 ผลตรวจสุขภาพ | บันทึกผลตรวจแต่ละครั้ง (แนบไฟล์ PDF/รูปได้), ตารางเทียบทุกปี ไฮไลต์ค่าที่เกินเกณฑ์, กราฟแนวโน้มรายการ |
| ⚙️ ตั้งค่า | หมวดหมู่ + งบประมาณ, บัญชี, กองเงินออม, รายการตรวจสุขภาพ + เกณฑ์ปกติ, เป้าหมาย, ขั้นภาษี |

## ติดตั้ง (ทำครั้งเดียว ~10 นาที)

### 1. วางโค้ดใน Apps Script ของชีต

1. เปิด Google Sheet **งบประมาณประจำปี**
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ในหน้า Apps Script สร้างไฟล์ตามตารางนี้ แล้วคัดลอกเนื้อหาจากโฟลเดอร์ [`src/`](src) ไปวาง

   | ไฟล์ใน repo | สร้างใน Apps Script เป็น | ชื่อไฟล์ |
   |---|---|---|
   | `src/Config.gs` | สคริปต์ (＋ → Script) | `Config` |
   | `src/Db.gs` | สคริปต์ | `Db` |
   | `src/Setup.gs` | สคริปต์ | `Setup` |
   | `src/Import.gs` | สคริปต์ | `Import` |
   | `src/Plan.gs` | สคริปต์ | `Plan` |
   | `src/Api.gs` | สคริปต์ | `Api` |
   | `src/Index.html` | HTML (＋ → HTML) | `Index` |
   | `src/Styles.html` | HTML | `Styles` |
   | `src/App.html` | HTML | `App` |

   - ไฟล์ `Code.gs` ที่มีมาให้ตอนแรก ลบทิ้งได้ (หรือลบเนื้อหาข้างในให้ว่าง)
   - ตั้งชื่อไฟล์**ไม่ต้องใส่นามสกุล** Apps Script เติมให้เอง ชื่อต้องตรงตามตาราง (โดยเฉพาะ `Index`, `Styles`, `App`)
4. (แนะนำ) ⚙️ **Project Settings** → ติ๊ก **Show "appsscript.json" manifest file in editor**
   แล้วเปิดไฟล์ `appsscript.json` วางเนื้อหาจาก [`src/appsscript.json`](src/appsscript.json) (ตั้งโซนเวลาเป็นกรุงเทพฯ)
5. กด 💾 **Save**

### 2. สร้างแท็บและนำเข้าข้อมูลเก่า

1. กลับไปที่ Google Sheet แล้ว**รีเฟรชหน้า** จะเห็นเมนูใหม่ **💰 แอปการเงิน**
2. เลือก **💰 แอปการเงิน → 1) ติดตั้ง / สร้างแท็บของแอป**
   - ครั้งแรก Google จะขอสิทธิ์ → เลือกบัญชีตัวเอง → *Advanced* → *Go to (ชื่อโปรเจกต์) (unsafe)* → *Allow*
     (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่เราเขียนเอง ยังไม่ได้ผ่านการตรวจของ Google — สคริปต์นี้เข้าถึงแค่ชีตนี้และโฟลเดอร์ไฟล์แนบใน Drive ของเรา)
3. เลือก **💰 แอปการเงิน → 2) นำเข้าข้อมูลเก่า** แล้วรอจนขึ้นสรุปจำนวนรายการ

### 3. เปิดเป็นเว็บแอป

1. ในหน้า Apps Script กด **Deploy → New deployment**
2. ⚙️ (Select type) → **Web app**
3. ตั้งค่า:
   - **Execute as:** Me
   - **Who has access:** **Only myself** ← สำคัญ: ให้เข้าได้เฉพาะเรา
4. กด **Deploy** → คัดลอก **Web app URL** ไปบุ๊กมาร์กไว้ (หรือเปิดจากเมนู 💰 แอปการเงิน → เปิดเว็บแอป)

### อัปเดตโค้ดภายหลัง

วางโค้ดใหม่ → Save → **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
(URL เดิมใช้ต่อได้)

- แท็บใหม่และค่าตั้งค่าใหม่จะถูกสร้างให้อัตโนมัติตอนเปิดเว็บ ไม่ต้องรัน setup ซ้ำ
- ถ้าเคยใส่ `SPREADSHEET_ID` ใน `Config.gs` ไว้ อย่าลืมใส่กลับหลังวางไฟล์ใหม่ทับ

### อัปเดตเป็นเวอร์ชันที่มี "แผน/คาดการณ์"

1. **เพิ่มไฟล์ใหม่** `Plan` (＋ → สคริปต์) แล้ววางเนื้อหา `src/Plan.gs`
2. **วางทับ** ไฟล์ที่แก้: `Config`, `Setup`, `Import`, `Api`, `Index`, `Styles`, `App`
3. Save → Deploy เวอร์ชันใหม่
4. เปิดเว็บ → **แผน/คาดการณ์** → กด **นำเข้าแผนจาก Expen Life** (นำแผน 12 เดือนข้างหน้าที่เคยวางไว้ในชีตมาเป็นค่าตั้งต้น)
5. ตรวจค่าในหน้า **ตั้งค่า → เป้าหมายและค่าตั้งค่า**: เงินเดือน, % ขึ้นเงินเดือน, เดือนที่ขึ้น, โบนัส, เงินเฟ้อ, ผลตอบแทน, ปีเกิด, อายุเกษียณ

> ทางเลือกสำหรับคนถนัด command line: ใช้ [clasp](https://github.com/google/clasp) กับโฟลเดอร์ `src/` (`clasp clone <scriptId> --rootDir src` แล้ว `clasp push`)

## สิ่งที่ควรทำหลังนำเข้าข้อมูล

1. **บันทึกยอดสิ้นเดือนในหน้า เงินออม/ลงทุน 1 ครั้ง** ด้วยยอดจริงของแต่ละกอง
   ข้อมูลเงินออมที่นำเข้ามาจากคอลัมน์ Save ใน Expen Life เป็นยอด "ลงเงิน" สะสม ไม่ได้หักการถอนออก
   (เช่น เงินสำรองฉุกเฉินจากการนำเข้า ≈ ฿133,000 แต่ในแท็บ Investment Tracking ยอดจริงคือ ฿86,000)
   พอบันทึกยอดจริงแล้ว มูลค่าและเป้าหมายจะถูกต้อง
2. ตรวจ/ปรับ **งบประมาณรายหมวด** ในหน้า ตั้งค่า (ค่าเริ่มต้นตั้งจากค่าเฉลี่ยใน Expen Life)
3. เพิ่ม **รายการประจำเดือน** (เงินเดือน, กยศ., ค่าเน็ต, ประกันสังคม …) ในแท็บ รายรับ-รายจ่าย → รายการประจำเดือน
4. ใส่ **ผลตรวจสุขภาพ** ย้อนหลังของแต่ละปี

## แผน / คาดการณ์ ทำงานอย่างไร

- **ค่าตั้งต้นของแต่ละช่อง** (ตัวเลขสีเทา)
  - รายรับ: เงินเดือน (ล่าสุด หรือ `BASE_SALARY`) ขึ้น `SALARY_GROWTH_PCT`% ทุกเดือน `SALARY_RAISE_MONTH`, โบนัส `BONUS_MONTHS` เท่าในเดือน `BONUS_MONTH`, หมวดอื่นจากรายการประจำ
  - รายจ่าย: งบ/เดือนของหมวด (ถ้าไม่ได้ตั้งงบ ใช้ผลรวมรายการประจำของหมวด)
  - งวดผ่อน: แถว "↳ ผ่อน: …" แยกต่างหาก มาจากแท็บแผนผ่อน
  - เงินออม: `SAVING_RATE_TARGET`% ของรายรับตามแผน
- **ช่องที่แก้เอง** (ตัวหนา) เก็บในแท็บ `App_Plan` ลบตัวเลขให้ว่างเพื่อกลับไปใช้ค่าตั้งต้น
- **แผน vs จริง** เทียบกับรายการที่บันทึกจริง (บันทึกเป็นก้อนรายสัปดาห์ได้ เช่น ค่าขนมสัปดาห์นี้ 700)
- **คาดการณ์ถึงเกษียณ**: ปีแรก = ผลรวมแผน 12 เดือนข้างหน้า ปีต่อไปรายรับ/เงินออมโตตามเงินเดือนขึ้น รายจ่ายโตตามเงินเฟ้อ เงินออมสะสมเริ่มจากมูลค่าปัจจุบันทุกกองและงอกเงยตาม `RETURN_PCT`

## ข้อมูลเก่าถูกนำเข้าอย่างไร

| แท็บเดิม | นำเข้าเป็น |
|---|---|
| Income (เงินเดือน, Bonus, Extra, ปันผล, เงินคืน FWD) | รายรับ ลงวันที่ 1 ของเดือน |
| Expen Life (เฉพาะเดือนที่ไม่เกินเดือนปัจจุบัน — แถวอนาคตเป็นแผน) | รายจ่ายแยกหมวด ลงวันที่ 1 ของเดือน, คอลัมน์ Save → การลงเงินในหน้าเงินออม |
| เทมเพลท รายได้/รายจ่าย 2567 | เฉพาะเดือนที่ Income / Expen Life ไม่มี (ม.ค.–ก.ย. 2567) |
| ข้อมูลการยืม + ตารางผ่อน | เงินให้ยืม + งวดรับชำระ (รหัส Dept-xxx เดิม) |
| Tax | ค่าลดหย่อน/ภาษีหัก ณ ที่จ่าย ปี 2024–ปีปัจจุบัน (ปีที่ผ่านไปแล้วเก็บรายได้ทั้งปีตามตารางเดิม) |
| Credit Note book, Saving, Investment Tracking, Diagram fund flow, Summary | ไม่นำเข้า (ยังเปิดดูได้ในชีตตามเดิม) |

- รายการที่นำเข้ามีป้าย "นำเข้า" ในหน้าเว็บ
- ถ้าอยากนำเข้าใหม่ (เช่น แก้ข้อมูลเดิมแล้ว): เมนู **ลบข้อมูลที่นำเข้า** → **2) นำเข้าข้อมูลเก่า** (รายการที่บันทึกเองไม่ถูกลบ)
- การจับคู่คอลัมน์ → หมวด/บัญชี อยู่ที่ตัวแปร `LEGACY` ใน `src/Import.gs` แก้ได้ถ้าโครงสร้างแท็บเดิมเปลี่ยน

## โครงสร้างข้อมูล (แท็บที่แอปสร้าง)

| แท็บ | เก็บอะไร |
|---|---|
| `App_Transactions` | รายรับ-รายจ่าย 1 แถวต่อ 1 รายการ |
| `App_Recurring` | รายการประจำเดือน |
| `App_Categories` / `App_Accounts` | หมวด + งบ/เดือน, รายชื่อบัญชี |
| `App_Funds` / `App_Contributions` / `App_FundSnapshots` | กองเงินออม, การลงเงิน, ยอดสิ้นเดือน |
| `App_Loans` / `App_LoanPayments` | เงินให้ยืม, งวดรับชำระ |
| `App_Tax` / `App_TaxBrackets` | ข้อมูลภาษีรายปี, ขั้นภาษี |
| `App_HealthItems` / `App_HealthVisits` / `App_HealthResults` | รายการตรวจ + เกณฑ์, การตรวจแต่ละครั้ง, ค่าผลตรวจ |
| `App_Plan` | ช่องแผนรายเดือนที่แก้เอง/นำเข้า |
| `App_Installments` | แผนผ่อนของชิ้นใหญ่ |
| `App_Config` | เป้าหมาย, อัตรา USD/THB (สูตร `GOOGLEFINANCE`), ค่าระบบ |

แก้ข้อมูลตรงในแท็บเหล่านี้ได้ (แถวแรกเป็นหัวคอลัมน์ ห้ามเปลี่ยนชื่อ)
ไฟล์แนบ (ใบเสร็จ, ผลตรวจ) เก็บในโฟลเดอร์ Drive **"แอปการเงิน - ไฟล์แนบ"** ของเราเอง (ไม่แชร์ให้ใคร)

## โครงสร้างโค้ด

```
src/
  Config.gs     ค่าตั้งต้น, โครงสร้างแท็บ, ค่าเริ่มต้น (หมวด/บัญชี/กอง/รายการตรวจ/ขั้นภาษี)
  Db.gs         อ่าน/เขียนตารางในชีต + ตัวช่วยแปลงวันที่/ตัวเลข
  Setup.gs      เมนูในชีต, สร้างแท็บ, โฟลเดอร์ไฟล์แนบ, config
  Import.gs     นำเข้าข้อมูลจากแท็บเดิม
  Plan.gs       แผนรายเดือน, แผน vs จริง, คาดการณ์ถึงเกษียณ, แผนผ่อน
  Api.gs        doGet + API ทั้งหมดที่หน้าเว็บเรียก (ผ่าน api(name, argsJson))
  Index.html    โครงหน้าเว็บ
  Styles.html   CSS
  App.html      JavaScript ฝั่งหน้าเว็บ (Chart.js สำหรับกราฟ)
```
